# ADR-0001：使用程序化资产和原创合成音频

## 状态

Accepted

## 日期

2026-07-12

## 背景

项目需要一个适合儿童体验、可公开放置在 GitHub 的 3D 战斗原型。直接提交电视截图、官方 3D 模型或主题曲录音会带来版权和分发风险，也会让仓库无法在没有外部素材的情况下复现。

## 决策

使用 Three.js 在运行时生成城市、角色、怪兽、攻击特效和环境；使用 WebAudio 合成原创音乐与战斗音效。角色名称和故事设定保留在项目说明中，但不把相关第三方商标或影视素材声明为本项目资产。

## 备选方案

### 直接提交官方素材

视觉辨识度高，但需要明确的授权，且不适合默认公开分发。拒绝。

### 使用网络上的免费模型或音频

授权条款、署名要求和再分发范围不一定清楚，审计成本高。拒绝作为默认依赖。

### 先不做声音

减少版权风险，但会损失战斗反馈和儿童可理解性。拒绝；改用原创 WebAudio 合成。

## 后果

- 克隆仓库后不需要下载额外素材即可运行和构建。
- 视觉风格由代码控制，后续可以在获得授权后替换为合法素材。
- 程序化模型不等同于官方角色授权；公开部署和商业用途仍需自行确认第三方权利。
