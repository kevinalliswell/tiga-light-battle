# 迪迦：光之决战

一个面向 10-12 岁孩子的原创程序化 Three.js 空战小游戏。玩家操控 3D 迪迦在城市上空迎战随机怪兽，练习移动、形态切换、光线攻击和最终决战。

## 快速开始

环境要求：Node.js 20 或更高版本。

```bash
git clone https://github.com/kevinalliswell/tiga-light-battle.git
cd tiga-light-battle
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。

## 游戏操作

| 按键 | 操作 |
| --- | --- |
| `←` / `→` | 地面移动 |
| `↑` 连续按 3 次或长按 3 秒 | 起飞进入空战 |
| `B` | 从地面或天空直接进入宇宙空战 |
| `7` | 从空战返回地面 |
| `K` + `N`（10 秒内，顺序不限） | 第一视角 / 第二视角切换 |
| `↓` | 防御 |
| `Q` | 光拳 |
| `W` | 远程飞踢，带飞踢姿势和轨迹 |
| `E` | 迪迦飞镖 |
| `Z` / `X` / `C` | 对应形态光线 |
| `D` | 超级时空闪电 |
| `1` / `2` / `3` | 强力型 / 复合型 / 空中型 |
| `4` | 闪耀型；必须先被加坦杰厄击败并完成奥特曼石像信念复活 |
| `5` | 光之进化 |
| `6` | 只有闪耀型可对迪莫杰厄使用体内爆破 |
| `O` | 能量低时使用手电筒；石化后触发复活 |

起飞后镜头会拉远，城市显得更小。按 `B` 会直接进入更高的宇宙空战层。Melba 只能升到天空；基里艾洛德人和迪莫杰厄可以追入宇宙。地面怪兽无法进行近战命中，迪莫杰厄可以发射光束攻击空中的迪迦。

按下 `K` 或 `N` 后，在 10 秒内按另一个键，可在第一视角和第二视角之间切换。第一视角会隐藏迪迦自身模型，直接从头部高度观察战场。

| --- | --- |
| `npm run dev` | 启动 Vite 开发服务器 |

## 项目结构

```text
src/
  game/
    Game.ts          # 游戏循环、输入、战斗和空战状态
    models.ts        # 城市、怪兽档案和形态应用
    tigaModel.ts     # 程序化迪迦模型
    monsterModels.ts # 程序化怪兽模型
    effects.ts       # 光线、飞踢、爆炸和复活特效
    audio.ts         # WebAudio 原创合成音乐和战斗音效
    rules.ts         # 形态、伤害、能量和复活规则
  ui/hud.ts          # HUD、教程和键盘/触屏控制
```

项目不依赖外部 3D 模型、图片或电视原声：角色、城市、怪兽、特效和声音均由代码运行时生成。这让项目适合教学、实验和后续替换为拥有授权的素材。
