# 迪迦：光之决战

一个程序化 Three.js 剧情战斗游戏。52 集章节采用游戏内 3D 演出与可操作战斗交替推进；第 52 集结束后，黑屏显示「两年后」，进入梅加洛杰厄特别篇。剧情、造型与动作是游戏改编，不包含电视剧片源；部分怪兽共用基础模型。

> 本仓库是非官方的学习与创作项目，与圆谷制作株式会社或任何官方奥特曼产品没有隶属关系。代码和程序化实现按本仓库许可证发布；迪迦、奥特曼及相关角色名称、标志和商标不因本许可证获得授权。详见 [NOTICE.md](NOTICE.md)。

## 快速开始

环境要求：Node.js 20 或更高版本。

```bash
git clone https://github.com/kevinalliswell/tiga-light-battle.git
cd tiga-light-battle
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。

## 游戏操作

默认采用「剧情优先」：每集 42 秒人物剧情、约 15–30 秒自动战斗、18 秒战后对话。自动演出会走位、变身、连招并使用符合剧情条件的终结技，不需要反复按攻击。右上角可随时切换「手动战斗」或「自由探索」；自由探索暂停怪兽追击与能量消耗，点击「返回战场」可回到原始战斗区域。

三维移动支持地面前后左右，拖动画面旋转镜头，滚轮缩放。城市街区会随移动循环生成，角色没有固定横向、纵深或飞行高度上限。持续升空会经过城市、云层和深空的视觉阶段；这是程序化探索场景，不是按真实天体距离模拟的无限宇宙。人类依然不能飞行。

底部招式栏可直接点击，星级表示威力。点击招式会自动切换到所需形态；闪耀招式仍需先解锁。强化敌人不能被低等级招式终结，装甲弱点会显示在招式栏上方。通常怪兽生命降至 35% 后才能使用终结招式；第一集哥尔赞钻地时也有 6 秒瞄准窗口。

每集从人类开始。普通章节在同一集倒下三次后自动唤醒闪耀；加坦杰厄与梅加洛杰厄战中倒下一次即可。第 25 集的基里艾洛德人二代独立登场，危急时触发众人举光与自动光线反击，不受第 3 集初代胜负影响。

变身、危急救援与终结技等高潮默认播放原创器乐伴奏，平时安静。可在右上角导入本地《奇迹再现》音频替换伴奏。仓库不附带该歌曲，刷新页面后需重新导入。

镜头会跟随角色在三维空间移动。飞行时用 `←` / `→` 横移、`↑` / `↓` 升降，`F` / `J` 控制前后方向，`Y` 防御。升至太空可看见地球与星空。按 `B` 起飞，按 `7` 开始下降；「返回战场」可直接返回地面。

Melba 只能升到天空；基里艾洛德人可以追入宇宙。迪莫杰厄不能飞，只在地面发射覆盖地球范围的光线：每次一条大光线和多条小光线；进入宇宙后无法攻击。

按下 `K` 或 `N` 后，在 10 秒内按另一个键，可在第一视角和第二视角之间切换。第一视角会隐藏迪迦自身模型，直接从头部高度观察战场。

## 开发命令

### 零血最后反击与四星终结技

奥特曼生命降到 0 后仍能行动 30 秒，画面显示倒计时；倒计时结束才会 KO。只要先击败本集最后一只怪兽，即使生命仍为 0，也判定本集胜利。倒计时不会因再次受击而重置，飞行爆炸的 30 秒演出期间不会倒地。

可选择迪迦、赛罗、戴拿、盖亚、泽塔、特利迦与亚索，切换角色会重新开始当前剧集，装载对应场景、敌人与招式。赛罗可切换终极铠甲、光辉型、光辉终极铠甲。光辉终极铠甲与大闪耀在累计死亡 10 次后解锁，进度保存在当前浏览器；大闪耀无限能量、免疫伤害，小闪耀每集可用 60 秒，普通形态 180 秒。

战机有 50 点生命，驾驶时按 Q 发射、P 跳伞；跳伞会空中变身并解锁滑行。强力 / 复合 / 空中 / 小闪耀的高跳分别为 500 / 700 / 1000 / 10000 米，大闪耀标称跳跃高度为 11000000000000000000 米，镜头采用压缩比例展示。按住空格再按 B（或点击飞行爆炸）可连续飞行爆炸，20 秒飞出银河系，再俯冲返回，总时长 30 秒。特别篇后是第 53 集怪兽总攻，怪兽分批增援，飞行爆炸可清除整场总攻。

生命为 0～30 点时长按空格可使用 **奥特爆炸 ★★★★**，终结附近 40 距离内的怪兽，包括最终怪兽。按 `V` 或点击 **深空重砸 ★★★★**，迪迦会升空、飞出太阳系，在太阳和八颗行星的全景中逐渐缩小，再带着火焰俯冲回战场；落地后才对锁定目标结算终结伤害。深空重砸耗时 8 秒，需在零血倒计时结束前落地，普通战斗中仍在接近结尾时开放。

## 项目结构

```text
src/
  game/
    Game.ts          # 游戏循环、输入、战斗和空战状态
    models.ts        # 城市、怪兽档案和形态应用
    tigaModel.ts     # 程序化迪迦模型
    monsterModels.ts # 程序化怪兽模型
    effects.ts       # 光线、飞踢、爆炸和复活特效
    audio.ts         # 战斗音效、本地高潮配乐导入
    episodes.ts      # 52 集章节与特别篇
    storyRules.ts    # 招式强度、终结与剧情分支
    rules.ts         # 形态、伤害、能量和复活规则
  ui/hud.ts          # HUD、教程和键盘/触屏控制
```

项目不依赖外部 3D 模型、图片或电视原声：角色、城市、怪兽、特效和声音均由代码运行时生成。这让项目适合教学、实验和后续替换为拥有授权的素材。
